# Ícones

Os ícones de navegação e ação da interface são gerados localmente em SVG por
[`js/components/icons.js`](../../js/components/icons.js) (nenhuma fonte de ícone
externa, nenhum sprite baixado de CDN). Este diretório guarda apenas o ícone
estático do aplicativo (`app-icon.svg`), usado como referência visual da marca —
o favicon embutido no `index.html` é gerado a partir do mesmo desenho.
